# Radio Friday 视觉系统

中文陪伴聊天、直播与小说阅读，以雨夜电台和书页中的城市为视觉线索。桌面端统一使用中性的深色黑白灰：炭黑页面、深灰内容面板、浅灰文字与柔白主按钮，不使用暖白或棕色品牌点缀。用不同灰度和边界建立层次，避免大片纯白。登录图片保留原有摄影内容，界面控件与站内共享配色。手机端保留现有外观，并纳入同一套语义 token。

## 实现约定

**整个项目的前端统一使用 Tailwind CSS v4。** 这是用户明确指定的项目约定。

- `apps/web/src/app/theme.css` 是设计 token 的唯一入口，`globals.css` 导入并提供共享组件样式。
- 页面优先使用 JSX 中的 Tailwind 工具类；共享样式在 `@layer components` 中组合 `@apply`。功能样式文件通过 `@reference` 引用全局入口，消费相同的 token。
- 新颜色按用途命名，不在页面内写十六进制颜色，不覆盖 Tailwind 的 `slate` 调色板来间接改变全站颜色。
- 保留复杂布局、图片遮罩、动画和浏览器自动填充所需的 CSS。动态数值可以使用 CSS 自定义属性。
- 品牌、聊天、直播、阅读、账户管理复用现有组件；修改视觉时保留认证、身份继承与消息权限逻辑。

语义 token 通过 `@theme inline` 映射到 `--rf-*` 变量。768px 及以上在根节点应用 `theme-graphite`；登录与媒体舞台的局部场景也使用 `md:theme-graphite`，避免局部暖色覆盖桌面主题。768px 以下保持原有根变量，登录与媒体舞台保留 `theme-night`。这些场景都消费相同的 Tailwind 工具类，不复制组件。图片上的文字和遮罩使用 `photo-*` token，桌面为中性灰，手机保留原值。`bg-bg`、`bg-panel`、`text-ink` 和 `border-line` 保持现有组件兼容。

- 成功、错误、提醒分别使用 `success`、`danger`、`warning`，各自配套 `-soft` 背景与 `-line` 边框，保留文字或图标说明。
- 中文采用苹方/微软雅黑，Radio Friday 字标采用 Georgia（`font-brand`）。站内主标题 24–28px，正文 14–16px，辅助文字 12–14px；阅读正文 16px、1.9 倍行高。
- 间距以 Tailwind 的 4px 步进为主；控件圆角 `rounded-control` 为 10px，面板 `rounded-panel` 为 14px。头像与状态点使用圆形。
- 普通内容使用实色面板，以背景、边界和留白建立层次；阴影统一为 `shadow-panel`、`shadow-popover`、`shadow-dialog`。
- 登录场景保留图片，桌面控件与装饰采用中性灰，手机沿用现有配色。主按钮不带箭头；卡片边框以 14 秒周期缓慢流动，减少动态效果时停用。

## 组件与状态

- 主按钮：`btn-primary`，桌面使用柔白填充和深色文字；次按钮：`btn-secondary`，面板底色与清晰边界；危险操作：`btn-danger-ghost`。按钮至少 44px 高，禁用时降低不透明度并显示禁用光标。
- 输入框：`input-field`，独立的控件边界，聚焦时使用 `border-focus` 与轻微焦点环；触屏输入字号 16px，禁用时使用次级表面。
- 导航：桌面采用灰色选中背景、浅灰文字和图标；保持 `aria-current`。
- 卡片：复用 `surface`、`content-panel`、`person-card`，使用面板 token，统一边框与圆角。
- 筛选表单：独立面板，筛选为主按钮，重置为次按钮；手机两列、宽屏四列。
- 聊天气泡：自己的消息使用主操作色与反色文字，对方使用面板底色；保留发送状态和消息来源语义。
- 空状态：使用实色面板、虚线边界和说明；加载、错误与无内容分别呈现。身份继承始终保留跳过入口。
- 阅读：正文区域使用 `bg-reading`，桌面为中性深灰，正文与章节导航保持统一文字层级。

## 页面结构

登录页按照参考图分为左侧认证表单和右侧场景图片。表单左对齐，品牌在顶部，说明在底部；左右区域之间不设竖分割线。三张用户提供的图片分别对应陪伴、电台与阅读。首屏使用 Messages across the rain 图片；每 5 秒自动切换，当前场景下方的进度条在 5 秒内从左向右填满；切换场景或再次点击当前场景时重置进度与计时。保留手动选择场景，不提供暂停按钮，悬停和键盘焦点不会暂停轮播。系统偏好减少动态效果时取消过渡动画。场景文案收于底部，保留图片本身的聊天内容。

```
Radio Friday              此刻，同频
                          雨夜主播 / 窗边陪伴 / 书页城市
欢迎回到你的频率。
手机号                    把心事，调到同一个频率。
密码                      简短场景说明
登录                      标签
手机号注册                电台 | 陪伴 | 阅读
```

760px 以下保留现有手机端登录、注册的图片背景、布局、字号与交互，不在全站主题调整中重新设计。手机端同样消费共享 token；深色语义由 `theme-night` 提供，图片遮罩通过 `photo-mobile-shade` 保留现有颜色。注册先验证手机号，再设置密码、昵称和性别，保留互动说明及后续身份继承流程。

站内桌面采用 236px 左侧导航，768px 以下为顶部品牌和四项导航。聊天、直播、小说和个人资料共享语义 token。桌面直播大厅与舞台均为中性深色，直播封面使用灰色表面，避免把主按钮的浅色扩大到整个封面。错误和成功状态保留语义颜色。

## 组件与可访问性

- 共享变量：`apps/web/src/app/theme.css`；共享组件样式：`apps/web/src/app/globals.css`。
- 登录、注册样式：`apps/web/src/features/auth/auth.css`。
- 图标库：`lucide-react`，按需导入，首页导航及表单图标统一采用 1.75–2px 线宽；标志 `RadioMark` 使用 `AudioLines`；页面标题：`PageHeading`。
- 所有界面的颜色使用 Tailwind 语义工具类；功能 CSS 的 `@apply` 与 JSX 使用同一组 token。
- 动态类名使用 `@/lib/utils` 的 `cn()`。
- 保留可见键盘焦点、表单标签、错误与加载反馈；注册步骤切换后聚焦标题；图片按钮提供选中状态；支持减少动态效果。

## 验证

- 使用 Node 22，运行 `pnpm --filter web typecheck` 与 `pnpm --filter web build`。
- 使用现有 Playwright 测试验证登录注册、身份继承、陪伴目录和直播流程；不通过视觉改动改变业务行为。
- 检查 320px、390px、768px 与 1440px 下的布局、表单焦点、弹窗、文字对比度和横向溢出。桌面检查文字、按钮、状态和媒体舞台，手机核对调整前后的颜色与布局一致。
