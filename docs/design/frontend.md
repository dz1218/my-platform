# 今晚视觉系统

产品服务中文陪伴聊天、直播和小说阅读。界面采用安静的青灰配色，内容左对齐，以稳定的页面结构和清晰的操作层级建立一致性。

## 设计变量

- 背景 `#F5F7F8`，面板 `#FFFFFF`，正文 `#24343B`，次要文字 `#62727A`，边界 `#DCE3E6`，主操作 `#355F6D`。
- 系统中文无衬线字体；主标题 24–28px，区块标题 14px / 600，正文 14–16px，辅助信息 12px。小说正文维持 15px、1.9 行高。
- 基础间距按 4px 递进；控件间距 8–12px，面板内边距 20px，区块间距 24px，页面顶部 24–32px。
- 面板圆角 12px，控件圆角 8px；40px 按钮高度；用边框表达分组，不用装饰性阴影。

## 页面结构

四个主页面共用 `.page-shell`，最大宽度由 `--layout-width: 960px` 控制；导航、标题、正文边界一致。导航高 60px。手机边距 16px，桌面 24px。

`PageHeading` 统一标题、说明、右侧操作和底部分隔线。主页面不再放重复的首页返回链接。返回链接用于详情与编辑页面。阅读与表单仍按内容限制行宽。

```
今晚                              陪伴 直播 小说 我的
页面标题                                  主操作
页面说明
──────────────────────────────────────────────
区块标题
内容区域
```

- 陪伴：最近聊天 / 所有朋友通过按钮切换，同一屏不重复列出同一批人物；人物网格在手机一列、平板两列、桌面三列。
- 直播：创建工具栏与房间列表分开；空状态只解释当前状态和下一步，不显示 API 等实现细节。退出账号统一放在「我的」。
- 小说：书架使用有分隔线的列表，标题、简介、作者与章节依次排列。
- 我的：资料和账号设置各自分组，普通说明链接使用中性色；红色只用于错误或危险操作。

## 组件规范

共享样式位于 `apps/web/src/app/globals.css`；标题组件位于 `apps/web/src/components/page-heading.tsx`。复用 `content-panel`、`panel-heading`、`settings-row`、`empty-state` 和按钮、输入框样式。新主页面不能自行指定不同最大宽度或标题基线。

保留可见焦点、语义标题、按钮选中状态、请求错误及加载状态；支持减少动态效果。紧凑化通过布局和间距完成，不做整页缩放。

项目使用 Tailwind 3，采用 frontend-design 与 tailwind-design-system 的设计变量和组件分层方法，使用当前版本支持的实现。

## Tailwind 与类名组合

聊天布局、消息气泡和输入区直接使用 Tailwind，已移除独立 CSS Module。`bg-bg`、`bg-panel`、`text-ink`、`text-muted` 和 `border-line` 引用全站 CSS 变量。

动态类名通过 `@/lib/cn` 的 `cn()` 组合：`clsx` 处理条件与数组，`tailwind-merge` 处理冲突的工具类。项目是 Tailwind 3，使用兼容的 tailwind-merge 2.6。静态类名保持字符串即可。自定义组件类（如 btn-primary）的内部声明不在自动合并范围内，不能依赖 cn() 解决这些类内部的冲突。
