# Radio Friday 双端视觉与体验系统

Radio Friday 是中文陪伴聊天、直播与小说阅读网站。桌面和手机共享暖黑、香槟金、雨夜摄影的品牌语言，手机有自己的页面组合和操作流程。整个前端使用 **Tailwind CSS v4**。

## 架构与共享边界

- 同一个 Next.js 工程、同一组路由、登录态和后端 API。服务端页面继续负责认证和服务端内容，不能为双端视图复制认证或权限判断。
- 业务控制层负责查询、缓存、权限、提交和实时连接；其下才是桌面／手机页面组合。`useCompanionHome`、`useLiveLobby`、`useConversation`、`useLiveRoom` 和 `useLiveVoice` 不随视图切换重新挂载。
- `useViewport` 是客户端页面的统一视口入口：小于 768px 为手机，其余为桌面。服务端与客户端首次渲染均返回未知视口，复杂页面先显示轻量骨架，避免 hydration 不一致或先展示桌面布局。
- `AppShell` 的桌面侧栏与手机底栏是没有业务副作用的导航组件。内容只渲染一份；小说正文、书封、账户信息等保持服务端渲染，通过内容组件和布局规则复用。
- 实时聊天室的连接、草稿和媒体节点位于稳定的组件层级中。手机的成员／连麦面板独立组合，舞台和聊天记录不因横竖屏切换而重建。
- 通用按钮、头像、书封、消息气泡、状态提示和表单字段共享；页面信息顺序、导航、筛选和操作面板可独立组合。

## 设计变量

`apps/web/src/app/theme.css` 是唯一 token 入口；`globals.css` 导入 token 并提供共享组件样式。页面优先使用 JSX 的 Tailwind 工具类；共享样式用 `@apply`，功能样式表用 `@reference` 引用全局入口。颜色不得写进业务组件。

| 用途 | 值 | 工具类 |
| --- | --- | --- |
| 页面背景 | `#1B1B19` | `bg-canvas` |
| 面板 | `#141413` | `bg-panel` |
| 次级表面 | `#262623` | `bg-surface-soft` |
| 悬停／选中表面 | `#33322E` / `#3B3933` | `bg-surface-hover` / `bg-surface-selected` |
| 正文 | `#F3F1EC` | `text-ink` |
| 次要文字 | `#B9B5AD` | `text-muted` |
| 提示文字 | `#AAA59C` | `text-faint` |
| 分隔线／控件边界 | `#41403B` / `#777269` | `border-line` / `border-control` |
| 主操作／反色文字 | `#DFBC89` / `#262522` | `bg-action text-on-action` |
| 品牌／焦点 | `#DFBC89` | `text-accent outline-focus` |
| 阅读背景 | `#1D1C19` | `bg-reading` |

根节点与局部 `theme-night` 使用同一套变量，不随系统明暗偏好变化。图片使用独立 `photo-*` token，成功、警告、错误使用各自语义色及 soft/line 配套变量，始终配文字说明。

- 字标采用 Georgia（`font-brand`），中文采用苹方／微软雅黑。桌面标题 28–32px，手机标题 24px，正文 14–16px，辅助文字至少 12px；阅读正文 18px、1.9 倍行高、最大宽度 680px。
- 4px 间距体系；控件圆角 10px、卡片 16px、摄影横幅 24px。桌面内容最大宽度 1440px，侧栏宽 236px。
- 金色用于主操作、焦点和少量品牌细节；列表、面板通过实色表面与留白分层，不叠加大面积发光效果。
- 摄影使用现有素材。`SceneBanner` 负责桌面 260px 横幅和紧凑场景；手机最近聊天没有横幅。新增场景没有自动轮播。
- 图标使用 lucide-react，1.75–2px 线宽；`RadioMark` 使用 AudioLines。

## 双端页面与导航

| 页面 | 桌面 | 手机 |
| --- | --- | --- |
| 陪伴 | 场景横幅、目录、最近聊天侧栏 | 最近聊天／发现朋友标签，只有发现页有紧凑摄影 |
| 人物目录 | 常驻筛选与多列虚拟列表 | 单列虚拟列表、搜索、筛选底部弹层 |
| 聊天 | 对话与宽屏设置侧栏 | 全屏对话、底部输入、全高设置面板 |
| 直播大厅 | 场景横幅、房间目录、创建面板 | 列表优先，开播入口打开底部表单 |
| 直播房间 | 舞台与互动侧栏 | 舞台上方、聊天下方，成员和连麦使用弹层 |
| 小说 | 摄影与书封网格 | 紧凑场景、双列书架 |
| 阅读 | 居中正文 | 沉浸正文、返回与章节操作 |
| 我的与身份 | 账户摘要、身份和设置分区 | 纵向账户设置、身份入口、单列身份选择 |

手机公共导航为底部四项：陪伴、直播、小说、我的。顶部由各页面呈现标题和动作，不重复堆放全局品牌栏。普通页面为底栏及安全区预留空间。

以下页面隐藏手机公共导航：`/chat/:id`、`/operator?id=…`、`/live/:id`、章节阅读页。编辑页不属于阅读沉浸页面。桌面保留侧栏。每个沉浸页面都提供返回入口。

- 陪伴支持 `view=recent|discover`。无指定值时在最近会话加载成功后选择默认标签：有会话选最近聊天，无会话选发现。自动选择只发生一次，手动标签通过浏览器历史记录保留，不受后台轮询影响。
- 筛选弹层打开时读取已应用值；应用后关闭，重置只修改弹层草稿，关闭时丢弃未应用值。手机姓名搜索独立提交。
- 陪伴目录保留虚拟化、加载更多、过滤状态。路由拦截保持目录挂载，进入聊天暂停后台目录操作，返回恢复目录锚点、滚动与焦点。
- 手机聊天回车换行、按钮发送；桌面 Enter 发送、Shift+Enter 换行。中文输入法组合期间不发送。发送失败保留草稿和原有重试逻辑。
- 聊天处理动态视口和底部安全区；连接与草稿不随视口变化重置。媒体节点保持稳定，不能复制两份舞台再用 CSS 隐藏其中一份。
- 小说书封仅对真实标题与作者做排版，不新增封面数据。身份继承保留选择、确认、跳过及本账户／AI 身份区别。

## 认证与组件状态

登录／注册延续原有摄影和布局，统一消费暖黑金色 token。保留 5 秒场景轮播、手动选择、减少动态效果，以及原有手机背景；不改认证和身份流程。注册先验证手机号，再设置密码、昵称和性别。

按钮至少 44px 高；输入框在手机为 16px；正文对比度至少 4.5:1。保留可见焦点、标签、禁用、加载、空状态、失败重试和权限反馈。共享 `Sheet` 使用原生 dialog，约束焦点、支持 Escape、关闭后恢复焦点，并处理安全区。动画尊重 prefers-reduced-motion。

## 验证

- Node 22：`pnpm --filter web typecheck`、`pnpm --filter web build`。
- `PLAYWRIGHT_CHANNEL=chrome pnpm --filter web test:live` 使用隔离测试服务，不能访问真实业务数据。
- 320、390、768、1440px 检查各页面、长内容、空状态、弹层、导航和横向溢出；截图写入测试产物及 `/tmp/radio-friday-review`。
- 回归认证、身份、聊天权限、目录返回恢复；补充手机标签、筛选草稿、发送键行为、跨断点连接／草稿保留与沉浸路由。
- 真实直播与连麦测试需本机 LiveKit，使用 `LIVEKIT_INTEGRATION=1`。真实手机软键盘、iOS 浏览器工具栏与硬件音视频需要另行设备验证，不以桌面视口模拟替代。
