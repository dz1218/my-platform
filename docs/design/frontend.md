# 今晚视觉系统

产品服务中文陪伴聊天、直播和小说阅读。界面采用安静的青灰配色，内容左对齐，以稳定的页面结构和清晰的操作层级建立一致性。

## 设计变量

- 背景 `#F5F7F8`，面板 `#FFFFFF`，正文 `#24343B`，次要文字 `#62727A`，边界 `#DCE3E6`，主操作 `#355F6D`。
- 系统中文无衬线字体；主标题 24–28px，区块标题 14px / 600，正文 14–16px，辅助信息 12px。小说正文维持 15px、1.9 行高。
- 基础间距按 4px 递进；控件间距 8–12px，面板内边距 20px，区块间距 24px，页面顶部 24–32px。
- 面板圆角 12px，控件圆角 8px；40px 按钮高度；用边框表达分组，不用装饰性阴影。

## 页面结构

桌面采用 216px 固定左侧导航，右侧内容占满剩余宽度。768px 以下切换为顶部品牌与四项导航；内容水平边距从 16px 随视口增加到 48px，不设置主页面最大宽度。使用原有青灰与白色，强调陪伴产品的安静氛围，不增加无意义的装饰区块来填充空间。

`AppShell` 统一导航和内容区域，登录、注册页独立呈现。`PageHeading` 统一标题、说明与操作。阅读正文与编辑表单保留适宜行宽，目录、主页面与聊天充分利用可用空间。

```
今晚        今天想和谁聊聊？
            认识一位新朋友，或继续上次没聊完的话题。
陪伴        ────────────────────────────────────
直播        这里的朋友                 最近聊天
小说        人物    人物    人物        对话列表
我的        人物    人物    人物
```

- 陪伴：朋友网格按可用宽度自动排列；1200px 以上右侧显示 300px 最近聊天栏，小屏顺序展示。人物使用真实姓名、年龄和匹配状态，不虚构在线状态。
- 聊天：占满可用高度与宽度，消息区独立滚动，标题和输入区固定在网格上下两端。
- 直播与小说：使用自适应网格，最小列宽 320px，窄屏一列；空状态提供下一步指引。
- 我的：宽屏并排展示资料与账号说明，窄屏上下排列。

## 组件规范

共享样式位于 `apps/web/src/app/globals.css`；标题组件位于 `apps/web/src/components/page-heading.tsx`。复用 `content-panel`、`panel-heading`、`settings-row`、`empty-state` 和按钮、输入框样式。新主页面不能自行指定不同最大宽度或标题基线。

保留可见焦点、语义标题、按钮选中状态、请求错误及加载状态；支持减少动态效果。紧凑化通过布局和间距完成，不做整页缩放。

项目使用 Tailwind 4，采用 frontend-design 与 tailwind-design-system 的设计变量和组件分层方法。主题直接在 globals.css 的 @theme 中配置，PostCSS 使用 @tailwindcss/postcss，不再保留 v3 配置文件。

## Tailwind 与类名组合

聊天布局、消息气泡和输入区直接使用 Tailwind，已移除独立 CSS Module。`bg-bg`、`bg-panel`、`text-ink`、`text-muted` 和 `border-line` 引用全站 CSS 变量。

动态类名通过 `@/lib/utils` 导出的 `cn()` 组合，直接使用 shadcn 官方的 `cn` 包，不维护本地实现，也不直接依赖 clsx 或 tailwind-merge。静态类名保持字符串即可。自定义组件类（如 btn-primary）的内部声明不在自动合并范围内，不能依赖 cn() 解决这些类内部的冲突。

官方来源：https://ui.shadcn.com/docs/installation/manual#add-a-cn-helper
